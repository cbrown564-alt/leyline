Case study

Elizabeth Norman International

A specialist recruiter's website, rebuilt so candidates and employers find their route in one click, and the team can update it without a developer.

Client Insight & analytics recruiter, since 1989 Size Small · about 4 weeks Live October 2026 · elizabethnorman.com

The problem

  • Nine equal menu items and a generic headline
  • An account and password needed to apply for a job
  • Closed jobs and test pages still public
  • WordPress admin too complex for the team to run

The website

  • Menu cut from nine items to five
  • One route each for candidates and employers
  • Apply in one form, CV optional
  • 117 redirects: every old link still works
  • Only current jobs in search results

The editing

  • Write and publish articles without WordPress menus
  • Edit main pages through labelled fields
  • Add, reorder or remove client logos on one screen

A logo change now takes 2 minutes instead of a developer.
